# Notify Release

Официальные релизы и список изменений музыкального плеера **Nicefy** для Android.

## Скачать

[Последняя версия Nicefy](https://github.com/ZoonderVK/Notify-Release/releases/latest) · [Список изменений](CHANGELOG.md)

В разделе Releases находятся подписанный APK, описание изменений, контрольная сумма и файл проверки обновлений `update.json`.

Установите APK поверх существующей версии, не удаляя приложение: так сохранятся настройки, очередь и библиотека. Требуется Android 8.0 или новее.

Начиная с 2.0.1, Nicefy проверяет обновления в фоне раз в сутки при открытии приложения. Проверить вручную можно в настройках. Перед загрузкой вы увидите письмо с изменениями и кнопками «Скачать» и «Позже». Установку подтверждает системный установщик Android; при необходимости разрешите установку из Nicefy.

## О репозитории

Этот репозиторий содержит только релизы и документацию. Исходный код приложения здесь не публикуется. Автоматически создаваемые GitHub архивы «Source code» содержат только файлы этого репозитория, а не исходники Nicefy.

Не публикуйте здесь токены, данные аккаунтов или ключи подписи. Для установки и проверки публичных обновлений аккаунт GitHub не нужен.
